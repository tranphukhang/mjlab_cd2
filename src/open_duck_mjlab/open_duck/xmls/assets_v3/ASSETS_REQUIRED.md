# Required STL assets

Copy the STL files from `tranphukhang/open_duck_mini_v2/xmls/assets_v3/` into this directory before running MJLab.

Required files:

- base_link.STL
- L1_hip_yaw.STL
- L2_hip_roll.STL
- L3_hip_pitch.STL
- L4_knee.STL
- L5_ankle.STL
- R1_hip_yaw.STL
- R2_hip_roll.STL
- R3_hip_pitch.STL
- R4_knee.STL
- R5_ankle.STL

The GitHub text API used to initialize this repository cannot copy binary STL payloads safely, so these files must be copied locally and committed with git.
